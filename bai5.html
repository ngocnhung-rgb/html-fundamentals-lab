Minh họa Cấu trúc Media và Văn bản trong HTML

1. Môi trường phát triển XAMPP & Apache

Apache đóng vai trò là máy chủ web cục bộ (local web server) giúp phục vụ các file HTML tĩnh qua giao thức HTTP tại địa chỉ http://localhost.

2. Quản lý phiên bản với Git và GitHub

Git giúp theo dõi lịch sử thay đổi mã nguồn, thực hiện commit các tính năng mới và đồng bộ dữ liệu an toàn lên remote repository trên GitHub.
